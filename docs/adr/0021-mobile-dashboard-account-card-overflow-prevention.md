# 0021. 手機儀表板帳戶一覽卡片防溢出與兩行標題排列 (Mobile Dashboard Account Card Overflow Prevention)

## Context
手機版儀表板「帳戶一覽」卡片右側被截斷。根因有二：
1. 卡片標題列將「圖示＋帳戶名稱」與「公帳/私帳徽章、類型徽章」排在同一橫列，無換行、無截斷。
2. 手機斷點下 `.grid-dashboard-main` 與 `.grid-2` 改為 `1fr`（等同 `minmax(auto, 1fr)`），子項目內容的最小寬度會撐開欄位，導致整張卡片超出螢幕；信用卡「🏠 代墊／👤 個人私帳」金額列同樣不換行。

## Decision
1. **帳戶卡片標題兩行排列（手機）**：第一行為「圖示＋帳戶名稱」，名稱過長以 `…` 截斷；第二行放「🏠 公帳／🔒 私帳」與「類型」徽章，可自動換行。
2. **信用卡代墊／個人私帳列（手機）**：「🏠 代墊」與「👤 個人私帳」各佔一行，金額靠右對齊。
3. **網格防撐寬**：手機斷點下 `.grid-dashboard-main`、`.grid-2` 改用 `minmax(0, 1fr)`，其子項目設定 `min-width: 0`，確保卡片不超出視窗寬度。
4. 桌面版版面維持不變。

## Consequences
- 手機上整張帳戶卡片完整顯示、無橫向截斷。
- 帳戶名稱過長時以省略號呈現，完整名稱可於帳戶管理頁檢視。
