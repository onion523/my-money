# 0009. 標準收支分類擴充與雙層智慧推薦引擎 (Curated Category Taxonomy and Two-Tier Recommendation Engine)

## Status
Accepted

## Context
在既有系統中，交易分類採用精簡的全域常數（支出 8 類：餐飲、交通、娛樂、購物、生活、醫療、教育、其他；收入 5 類：薪資、獎金、投資、兼職、其他）。
然而在實際個人與家庭記帳場景中，存在以下關鍵痛點：
1. **核心開銷無處安放**：如「房租水電、數位訂閱 (Netflix/Spotify/iCloud/AI)、汽機車輛油錢維修、保險稅費、寵物生活、旅行度假、社交紅白包」等高頻且大額的固定與變動開銷，目前全部被迫混入「生活」或「其他」，導致月度圓餅圖統計嚴重失真，預算設定亦失去精準度。
2. **缺乏智慧推薦**：網頁端每次記帳都必須手動展開下拉選單挑選；通訊軟體 Bot 端亦僅有粗略的正則表達式，無法自適應學習使用者的個人習慣（例如某用戶習慣將特定超市歸為「餐飲食材」，另一用戶習慣歸為「居家生活」）。

## Decision

經過設計樹訪談（`grill-with-docs`），我們達成以下架構決策：

### 1. Curated Category Taxonomy (標準擴充分類庫)
- **支出擴充為 16 類**：
  1. 餐飲 🍜
  2. 交通 🚇
  3. 汽機車輛 🚗 *(新增：與大眾運輸通勤分流)*
  4. 居家水電 ⚡ *(新增：自「生活」獨立出房租、管理費、水電瓦斯、家用網路)*
  5. 數位訂閱 📱 *(新增：串流、雲端、AI 工具、手機門號資費)*
  6. 購物 🛍️
  7. 生活 💡 *(五金耗材、日用雜支)*
  8. 娛樂 🎮
  9. 美妝保養 💄 *(新增：剪髮、護膚、化妝品、美甲)*
  10. 醫療 💊
  11. 教育 📚
  12. 寵物毛孩 🐱 *(新增：飼料、獸醫、美容、用品)*
  13. 旅行度假 ✈️ *(新增：機票、飯店住宿、出國裝備，與日常娛樂分流)*
  14. 社交人情 🧧 *(新增：禮金、奠儀、送禮、請客應酬)*
  15. 保險稅費 📑 *(新增：人身與財產保險、房屋稅、所得稅等)*
  16. 其他 📦
- **收入擴充為 8 類**：
  1. 薪資 💵
  2. 獎金 🎁
  3. 投資 📈
  4. 兼職 💼
  5. 政府補貼 🏛️ *(新增：租屋補貼、育兒津貼、節能補助、所得稅退稅)*
  6. 禮金餽贈 🧧 *(新增：長輩孝親、親友紅包)*
  7. 二手出清 ♻️ *(新增：二手物品拍賣出清)*
  8. 其他 📦
- **架構取捨**：不建立動態自訂分類資料表（Custom Categories Table），以標準精選庫確保家庭群組成員在統計分析、預算設定與圖表維度上的絕對一致性與可比性。

### 2. Two-Tier Category Recommendation (雙層分類推薦引擎)
當使用者在記帳表單輸入「交易名稱/備註」或透過 Bot 發送自然語句時，採雙層優先推薦管線：
- **Tier 1 - 個人歷史習慣優先 (Historical Note Memory)**：
  優先檢索該用戶（或家庭群組）近 3~6 個月內的交易備註歷史。若備註包含歷史曾記過之相同商家或關鍵字，優先採納使用者上次選擇的分類，尊重個人既定習慣。
- **Tier 2 - 生活語意規則詞庫兜底 (Lexicon Fallback)**：
  若歷史無相符紀錄，落入內建擴充生活語意詞庫進行匹配（涵蓋中油、台鐵、高鐵、Uber、Netflix、Spotify、健保、全聯、家樂福、貓砂等百組高頻商家與品牌）。
- **未命中**：保留當前手動選擇或預設值，不強迫變更。

### 3. Adaptive Category Preselection (自適應預選與防覆蓋鎖定)
- 網頁前端（Transactions 與 Dashboard Quick Record Modal）在備註輸入時，自動依推薦結果將分類下拉選單切換至目標類別，並呈現「✨ 已智慧推薦為【類別】」柔和微光提示。
- **防覆蓋鎖定 (User Choice Lock)**：若使用者在當次填表中主動點擊下拉選單手動修改分類，系統即時標記手動鎖定，後續打字絕不再覆蓋使用者意志。

### 4. 雙端運算管線與分工 (Execution Pipeline)
- **Web UI**：利用前端已載入之近期交易資料（`transactions`）構建 In-Memory 索引，在使用者打字時達成 **0ms 本地瞬時比對**，零 API 往返延遲。
- **Bot 端**：於 `bot.ts` 寫入資料庫前，執行單行極速 SQL 查詢歷史備註，無歷史紀錄則走後端擴充關鍵字字典。
- **視覺調色盤**：擴充 `Analytics.tsx` 之 `PIE_COLORS` 為 16 色溫暖水彩和諧色階，保證所有分類在圓餅圖上皆具備專屬辨識色。

### 5. 歷史帳目不變性 (Historical Ledger Integrity)
- 既有歷史資料庫中的舊交易（如過往記在「生活」或「其他」之紀錄）一律維持原樣，不以遷移腳本進行回溯批次修改，嚴守會計審計一致性。

## Consequences
- **優點**：
  1. 徹底消滅「房租水電、數位訂閱、汽機車、保險、寵物」無處可記的窘境，家庭財務分析精細度躍升。
  2. 記帳速度大幅加速，輸入備註即可自動預選分類，免去展開下拉選單搜尋的繁瑣步驟。
  3. 歷史記憶優先機制兼顧個人彈性與標準化分析。
- **缺點與因應**：
  - 分類選項數量增加至 16 項，若手動挑選時選單較長。透過「輸入備註自動預選」機制，能讓 80% 以上的記帳操作免除手動翻找下拉選單。
