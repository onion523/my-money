# 14. 全站三態視角統一正名（全部、公帳、私帳）與彈窗標籤精簡規範 (Unified Scope Terminology & Switch Hierarchy)

Date: 2026-10-02

## Status

Accepted

## Context

在《My-Money》個人與家庭雙帳本系統中，使用者需要頻繁在「個人帳務」與「家庭公帳」之間切換檢視或過濾。
然而，在過往迭代中，不同頁面間的視角切換按鈕文字、圖示及彈窗標籤存在顯著分歧：
1. **切換器文字不一致**：
   - `Dashboard`（首頁儀表板）與 `Analytics`（統計分析）：使用「全貌合併」、「🏠 家庭公帳」、「🔒 個人私帳」。
   - `Transactions`（交易明細）：使用「全部」、「🏠 家庭公帳」、「🔒 個人私帳」。
   - `Accounts`（帳戶管理）：使用「全部 (本人 + 家庭公用)」、「🏠 家庭公用 (共同基金/家庭卡)」、「👤 個人私帳」。
2. **彈窗二態切換冗贅**：記帳彈窗（Modal）中的帳本歸屬按鈕帶有冗長的括號補充說明（「🏠 家庭公帳 (公開)」、「🔒 個人私帳 (隱私)」）。
3. **列表與圖表標示不齊**：分析圖表副標題出現「合併 / 公帳 / 個人私帳」，與主切換列文字不對稱。

為建立清晰且直覺的視覺層次，降低使用者的認知負擔，需要確立全站統一的範疇語意與圖示呈現規範。

## Decision

我們決定將全站所有涉及帳本範圍切換與歸屬顯示的介面元素，全面統一正名為「**全部**」、「**公帳**」、「**私帳**」，並規範標準圖示與精簡格式：

### 1. 全站三態視角切換器 (3-Way Scope Switcher)
在全站 4 大核心頁面中，視角切換按鈕統一採用以下圖示與文字（語意值保持 `all`、`household`、`personal` 不變）：
- **`all`**：`🌐 全部`
- **`household`**：`🏠 公帳`
- **`personal`**：`🔒 私帳`

**適用頁面**：
1. `Dashboard.tsx`：頁面頂部帳本視角切換器。
2. `Transactions.tsx`：篩選工具列帳本分類切換器。
3. `Accounts.tsx`：視角切換器（Scope Filter），消除「(本人 + 家庭公用)」等括號贅詞。
4. `Analytics.tsx`：頂部範疇切換列與圖表副標題（`全部`、`公帳`、`私帳`）。

### 2. 彈窗記帳歸屬二態切換 (Modal Scope Toggle)
在所有新增/編輯交易與還款之表單彈窗（Modal）中，二選一切換按鈕統一移除括號說明：
- 原 `🏠 家庭公帳 (公開)` 簡化為：`🏠 公帳`
- 原 `🔒 個人私帳 (隱私)` 簡化為：`🔒 私帳`

**適用彈窗**：
- `Dashboard.tsx`：快速記帳 Modal。
- `Transactions.tsx`：新增/編輯交易 Modal。
- `Accounts.tsx`：信用卡繳費沖銷 Modal。

### 3. 卡片與列表標籤精簡 (Badges & Labels)
- 交易明細清單與帳戶卡片上的標籤文字，統一消除冗長後綴，明確標示為「🏠 公帳」與「🔒 私帳」。

## Consequences

### Positive
- **體驗高度一致**：全站所有頁面與彈窗的視角切換文案與圖示徹底統一，學習成本降至最低。
- **簡潔美觀**：去除「(公開)」、「(隱私)」、「(共同基金/家庭卡)」等括號干擾，在手機與窄螢幕裝置上更不易發生換行或破版。
- **純前端優化**：API 查詢參數（`scope=all|household|personal`）與資料庫欄位定義（`is_shared`, `is_joint`）完全維持不變，零遷移風險。

### Negative / Trade-offs
- 去除括號說明後，初次使用的新用戶可能需要透過直覺理解「公帳」即為家庭公開分享、「私帳」即為個人隱私。但搭配 🌐、🏠、🔒 語意圖示，能維持極高的意象辨識度。
