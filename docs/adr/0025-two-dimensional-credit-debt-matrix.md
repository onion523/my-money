# 0025. Two-Dimensional Credit Debt Matrix (信用卡雙層公私債務矩陣與已出帳拆解)

Date: 2026-10-16

## Status
Accepted

## Context
既有信用卡負債架構僅將欠款區分為「已出帳 (`balance`)」與「未出帳 (`unbilled`)」，而公私帳拆解（`shared_debt` 與 `personal_debt`）則是將兩者加總（`totalDue = balance + unbilled`）後進行全量籠統拆解。  
當銀行帳單寄達時，持卡人與家庭共同基金面臨以下核心困境：
1. **已出帳費用無法區分公私帳**：已出帳待繳款僅顯示單一總額，持卡人與伴侶無法確知當期帳單中究竟多少是家庭代墊公帳、多少是個人私密消費。
2. **卡費還款金額混淆**：點擊「繳家庭代墊」時，系統預設填入包含未出帳在內的全部公帳代墊額，導致共同基金提早溢繳尚未出帳之款項。
3. **他人私卡公帳脫敏粗糙**：他人私卡於家庭公帳視角僅能看見一個總公帳代墊額，無法看清當期帳單中共同基金應實繳金額。

## Decision
1. **建立信用卡雙層公私債務矩陣（Two-Dimensional Credit Debt Matrix）**：
   - 後端批次聚合計算與前端將信用卡欠款結構化擴展為四維指標：
     - `billed_shared_debt`：已出帳公帳待繳款（當期帳單應由家庭共同基金撥付繳納之法定金額）
     - `billed_personal_debt`：已出帳私帳待繳款（當期帳單應由持卡人個人自行繳納之金額）
     - `unbilled_shared_debt`：未出帳公帳累計（未出帳區間內累積之家庭代墊消費）
     - `unbilled_personal_debt`：未出帳私帳累計（未出帳區間內累積之個人消費）
   - 總代墊額 `shared_debt = billed_shared_debt + unbilled_shared_debt`
   - 總私帳額 `personal_debt = billed_personal_debt + unbilled_personal_debt`
   - 總待繳款 `totalDue = balance + unbilled`

2. **卡片 UI 雙層精準呈現**：
   - **已出帳待繳款區塊**：於金額下方直接標註 `公帳 NT$ X · 私帳 NT$ Y`。
   - **負債性質拆解區**：清楚對照呈現「已出帳待繳（當期帳單）」與「未出帳（累計中）」各自的公私帳組成。

3. **繳卡費操作預設金額與快捷切換**：
   - 點擊「繳家庭代墊」時，若 `billed_shared_debt > 0` 優先預設代入「已出帳公帳」金額；若為 0 則代入未出帳公帳。
   - 繳款彈窗提供快捷切換標籤：`[僅繳當期已出帳公帳]` 與 `[結清全部代墊公帳]`。
   - 共同基金還款流水（`is_shared = 1`）優先沖銷已出帳公帳，溢出部分沖銷未出帳公帳。

4. **他人私卡公帳視角脫敏防線**：
   - 他人私卡於公帳視角下清楚揭露 `billed_shared_debt`（本期已出帳公帳待繳）與 `unbilled_shared_debt`（未出帳公帳累計）。
   - 個人私密消費（額度、私帳已出帳、私帳未出帳、總待繳）全數嚴格脫敏遮蔽。

## Consequences
- 徹底消除帳單繳費時的算帳負擔，每期帳單共同基金與個人各該出多少一目了然。
- 共同基金繳納卡費時精準扣抵當期已出帳款項，防止提早溢繳未出帳消費。
- 他人私卡公帳視角下，伴侶或管理員能清楚掌握應撥款額度，同時完全捍衛持卡人私密消費隱私。
