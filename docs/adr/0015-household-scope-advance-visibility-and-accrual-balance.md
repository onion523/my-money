# 15. 帳戶管理公帳視角納入私帳代墊負債與權責資產核算規範 (Household Scope Advance Visibility & Accrual Balance)

Date: 2026-10-03

## Status

Accepted

## Context

在《My-Money》雙帳本系統中，家庭成員頻繁使用個人的現金錢包、活存銀行或個人信用卡（`is_joint = 0`）代為支付家庭生活公帳（`is_shared = 1`），形成家庭對成員個人的代墊債務。

然而在先前的實作中，當使用者於帳戶管理（`Accounts.tsx`）切換至「🏠 公帳（`scope === 'household'`）」時，系統僅查詢並展示 `is_joint = 1` 之實體共同帳戶：
1. **私卡代墊公帳負債隱形**：若成員使用個人信用卡代墊公帳，該卡雖累積了實質屬於家庭責任之待繳卡費（`shared_debt > 0`），但在公帳視角下完全隱形。家庭管理員與其他成員無法在帳戶頁得知家庭對外尚有多少卡費待繳，亦無法從共同基金直接執行「🏠 繳家庭代墊」。
2. **頂部可用餘額虛胖**：公帳視角的「💳 信用卡總待繳」僅計入共同信用卡，遺漏了個人私卡上的公帳代墊額；導致「💎 淨可用餘額」高估虛胖，無法真實反映扣除所有家庭應付代墊後的真實剩餘資金。
3. **現金與轉帳代墊缺乏總覽**：家庭成員墊付的現金與轉帳支出僅記錄於「家庭協同（`Family.tsx`）」，帳戶管理頁面完全欠缺對家庭待付代墊款的整體掌握。

為落實精準會計責任制（Accrual Responsibility）並兼顧成員個人隱私，需建立公帳視角代墊透視與資訊脫敏規範。

## Decision

我們決定在「帳戶管理（`Accounts.tsx`）」的「🏠 公帳」視角下，全面落實「**雙軌代墊呈現**」與「**精準會計責任法**」：

### 1. 信用卡專區納入個人私卡之公帳代墊 (Personal Card Shared Debt Visibility)
- **查詢條件擴展**：在 `GET /accounts?scope=household` 中，除了原有的 `is_joint = 1` 共同卡外，同時查詢包含尚未結清公帳代墊欠款（`shared_debt > 0`）之個人信用卡（`is_joint = 0`）。
- **嚴格脫敏公帳化 (Sanitized View)**：
  - 若目標卡片為他人私卡（`card.is_joint === 0 && card.user_id !== userId`）：
    - **僅揭示**：卡片名稱、持卡人姓名、卡片顏色、每月結帳/繳款日、家庭代墊公帳待繳額（`shared_debt`）。
    - **嚴格遮蔽**：卡片信用總額度（`credit_limit`）、個人私帳消費額（`personal_debt`）與未出帳明細，不向他人揭露。
    - **操作限制**：非持卡人僅能點擊「🏠 繳家庭代墊」（自家庭共同基金扣繳公帳待繳）；編輯、刪除、校準（Reconcile）與出帳作業（Rollover）按鈕一律隱藏，後端 API 嚴格禁止非持卡人執行出帳與校準。
- **繳款授權邊界適配 (`POST /accounts/pay-credit-card`)**：
  - 允許非持卡人從家庭共同基金為他人私卡繳納公帳代墊款（`is_shared = 1`）。若嘗試為他人私卡繳納個人私帳消費（`is_shared = 0`），後端強制攔截並回傳 HTTP 403 Forbidden。

### 2. 頂部資產統計四宮格落實權責制 (Accrual Balance Calculation)
- 在 `GET /accounts/balance?scope=household` 中：
  - **`ccBilled` / `ccUnbilled` / 信用卡總待繳**：納入全體家庭成員個人私卡上之「家庭代墊公帳待繳額（`shared_debt`）」，合併共同信用卡欠款一併計入家庭總負債。
  - **💎 淨可用餘額**：依公式 `共同現金 + 共同存款 - (共同卡欠款 + 私卡公帳代墊欠款)` 計算，真實呈現家庭在清償所有公帳負債後之淨可用流動性。

### 3. 帳戶頁面新增家庭代墊待沖款總覽橫幅 (Pending Advances Banner)
- 在帳戶管理頁「🏠 公帳」視角下，若家庭存在成員待報銷代墊款（`pending_reimburse > 0`），於頂部四宮格上方展示醒目的「📑 家庭代墊待報銷款」橫幅：
  - 統計各成員代墊待沖銷總額。
  - 提供快速導向「家庭協同（Family.tsx）」一鍵報銷之入口。

## Consequences

### Positive
- **真實財務全貌**：公帳視角完整反映家庭實質應付的私卡代墊與代墊待報銷款，消除可用資金高估假象。
- **操作無縫流暢**：家庭成員或管理員在帳戶管理頁即可直接從共同基金清償個人私卡中的公帳欠款，不必在不同頁面間來回確認。
- **隱私高度隔離**：他人私卡的個人信用額度與私密花費被嚴格遮蔽，保障成員個人隱私主權。

### Negative / Trade-offs
- 公帳視角下的信用卡數量與負債金額會隨成員刷私卡代墊動態變化，因此卡片上需明確標記「🔒 私卡代墊」Badge 以利視覺區分。
