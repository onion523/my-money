# 0022. 總覽「最近收支明細」與收支明細格式對齊及長文字自動換行 (Recent Transactions Format Alignment & Text Wrapping)

## Context
1. 總覽頁區塊名稱為「最近交易記錄」，與全站正名後的「收支明細」用語不一致。
2. 總覽的單筆列表與收支明細頁格式不同：缺少「📑 已出帳／🗓️ 延至下期」徽章、沒有「帳戶：」前綴、記帳人徽章位置不同。
3. 全域 `.tx-name` 設為 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis`，備註或徽章過長時整列被截成一行，內容看不到（收支明細頁與總覽皆受影響）。

## Decision
1. **正名**：總覽區塊標題改為「最近收支明細」，括號範疇後綴沿用全站三態用語：全部／公帳／私帳。
2. **單筆格式對齊**：總覽每筆與收支明細頁一致：
   - 第一行：`分類 · 備註`，後接 `🏠 公帳／🔒 私帳` 徽章、信用卡 `📑 已出帳`／`🗓️ 延至下期` 徽章。
   - 第二行：`日期 · 帳戶：{帳戶名稱}` 與 `👤 記帳人` 徽章。
   - 金額靠右、收入綠／支出紅。
   - 不顯示編輯／刪除按鈕、不依日期分組，仍顯示最近 6 筆。
3. **抽出共用元件**：以共用的收支明細項目元件（`TransactionRow`）渲染單筆內容，總覽與收支明細頁共用，避免日後格式再度分岔；操作按鈕以可選的 `actions` 插槽傳入。
4. **長文字自動換行**：`.tx-name` 取消 `nowrap` 與省略號，改為 `white-space: normal; overflow-wrap: anywhere; word-break: break-word`，徽章列允許 `flex-wrap`；`.tx-info` 維持 `min-width: 0`。收支明細頁與總覽一併適用，金額欄 `flex-shrink: 0` 保持完整。

## Consequences
- 兩處明細格式一致，信用卡出帳狀態在總覽也看得到。
- 備註再長都會換行完整顯示，不再被截斷。
- 單筆樣式只需在共用元件維護一處。
