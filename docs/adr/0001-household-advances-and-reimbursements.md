# 0001. 家庭公帳代墊資格認定與報銷沖帳機制 (Household Advances and Reimbursements)

## Context
家庭成員在日常生活中常交替使用「個人帳戶／私卡／現金錢包」或「家庭共同基金」支付公帳。過去只要標記為公帳支出（is_shared = 1），在統計代墊款時未檢驗扣款帳戶性質，且前端家庭頁面在載入時遺漏呼叫代墊 API，致使畫面恆顯示「暫無紀錄」；此外，僅顯示粗略統計總額而欠缺透明明細，造成伴侶間核對不易。

## Decision
1. **嚴格區分代墊與公款直接開銷**：
   - 只有自成員「個人私帳／個人信用卡／個人現金錢包」（`is_joint = 0`）扣款之公帳支出（`is_shared = 1`），才計入個人代墊待報銷。
   - 若由「家庭共同基金」（`is_joint = 1`）直接支付之公帳消費，屬於家庭基金之直接支出，嚴格排除於個人代墊之外。
2. **總額沖銷與雙向明細展開**：
   - 維持累計總額即時平帳機制（`pending_reimburse = total_advanced - total_reimbursed`）。
   - 在各成員卡片提供「查看代墊明細」就地展開功能，同時呈現「個人代墊消費明細清單」與「共同基金撥款報銷沖帳紀錄」，確保對帳公開透明。
   - `GET /households/advances` 在單一端點一併返回統計摘要與相關明細項目，保證前端展開時零延遲渲染。
3. **結清狀態指引**：
   - 當待報銷金額為 $0 時，卡片標示「已全數結清」，並保留代墊記帳說明指引。

## Consequences
- 杜絕了成員使用共同公款卡買菜卻誤列為個人代墊請款的邏輯漏洞。
- 伴侶雙方皆可在家庭介面清楚看見每一筆代墊與撥款時間、項目、付款帳戶與金額，核銷完全透明。
