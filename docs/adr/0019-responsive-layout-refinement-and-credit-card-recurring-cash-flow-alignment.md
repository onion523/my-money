# 19. 響應式佈局重構、名詞標準化與信用卡週期收支現金流平移 (Responsive Layout Refinement, Terminology Alignment & Credit Card Recurring Cash Flow Shift)

Date: 2026-10-03

## Status

Accepted

## Context

在全站多裝置使用與家庭公私帳協同測試中，陸續發現以下版面佈局、語意名詞與財務預測邊界問題：
1. **名詞歧義與冗贅**：
   - 「分攤平滑」一詞過於生硬，易被誤解為分期付款，應回歸直觀之「週期支出每月平均」。
   - 記帳行為本質為資金流轉收支，原「交易記錄 / 交易明細」名稱生硬且易與證券交易混淆，應正名為「收支明細」。
   - 家庭協同中「待報銷代墊總額」與「從共同基金一鍵報銷」字串過長，在手機窄螢幕中造成容器破版。
2. **手機版面截斷與橫向誤判**：
   - 側邊欄抽屜斷點僅設定為 `@media (max-width: 768px)`，導致現代手機在橫向（Landscape，寬度 844px~932px、高度僅 390px~430px）時被誤判為電腦桌面展開 240px 側邊欄，剩餘寬度嚴重不足致使右側卡片截斷。
   - 帳戶管理中信用卡卡片之三顆操作按鈕（`🏠 繳家庭代墊`、`👤 繳個人私帳`、`全額結清`）並列寬度超出卡片容器，造成小螢幕水平溢出。
   - 統計圖表（Analytics）圓餅圖在手機寬度下外環文字標籤被 SVG 外框切斷。
   - 家庭協同頁面（Family）之代墊操作按鈕（「報銷沖帳」與「查看代墊明細」）與成員名冊中過長的 Email 及加入時間擠壓溢出。
3. **視角按鈕色彩對比**：
   - 頂部三態視角切換器中，「🌐 全部」之 Unicode 深色地球圖示在櫻粉色（`#FF9E9E`）選中背景下對比度不足被吃色。
4. **信用卡週期收支現金流扣款日脫節**：
   - 在未來 30 天現金流預測中，設定扣款帳戶為「信用卡」之週期收支，原本排在扣款記帳日（`day_of_cycle`）；但實際生活中刷信用卡並不會立即造成銀行活存或現金流出，實質現金流出日為該信用卡之「繳款日（Payment Due Day）」。

## Decision

### 1. 領域名詞與繁中語意正名
- **Amortization**：全面正名為「週期支出每月平均」與「換算每月平均」，消除「分攤平滑」生硬贅詞。
- **Transaction**：全面正名為「收支明細」，全站導覽與標題統一。
- **Reimbursement**：文案精簡正名為「報銷沖帳」，總額標籤精簡為「待報銷總額」。

### 2. 複合響應式斷點與防破版架構
- **側邊欄抽屜化升級**：引進複合斷點 `@media (max-width: 960px), (max-height: 500px)`，只要螢幕寬度 <= 960px 或高度 <= 500px（橫向手機），側邊欄全面轉為隱藏式抽屜導覽與底部選單，提供橫向手機 100% 寬度可視區域。
- **信用卡操作按鈕自適應堆疊**：在螢幕寬度 < 600px 時，信用卡卡片底部三顆按鈕自適應轉為堆疊分行排列，徹底杜絕橫向水平溢出。
- **全部視角圖示高對比向量化**：採用純白高對比向量地球圖示（Lucide Globe），在粉紅背景啟用時清晰醒目。
- **圓餅圖手機端圖例呈現**：在手機端（<= 640px）隱藏圓餅圖本體外拉文字標籤，改由圓餅圖下方分類卡片清單完整呈現「類別、百分比 % 與金額」，避免外環切字。
- **家庭協同響應式自適應排版**：
  - 代墊卡片於小螢幕轉為「上方金額概覽、下方按鈕分層並列」，確保「報銷沖帳」與「查看代墊明細」完整顯示。
  - 成員名冊中信箱與加入時間允許彈性折行（word-break），防止單行超長撐爆版面。

### 3. 收支明細（Transactions）帳戶查詢與視角連動
- **新增帳戶下拉篩選**：收支明細頁面新增「帳戶」篩選選單，後端 API 支援 `account_id` 查詢參數。
- **三態視角連動過濾**：
  - 切換至「🏠 公帳」時，帳戶選單僅列出家庭共同基金帳戶與共同信用卡。
  - 切換至「🔒 私帳」時，帳戶選單僅列出個人名下帳戶。
  - 切換至「🌐 全部」時，列出所有可用帳戶；若原選取之帳戶不屬於新視角範疇，自動重設為「全部帳戶」。

### 4. 信用卡週期收支現金流平移 (Credit Card Recurring Cash Flow Shift)
- **實質現金流出日對齊**：當週期收支綁定扣款帳戶為「信用卡」時，其在現金流預測之事件日期自動由刷卡日平移至該卡所屬之「信用卡繳款日（Payment Due Day）」。
- **結帳週期精準推算**：依據週期項目發生日相較於信用卡結帳日（Statement Day）之先後，推算入帳週期並定位於未來 30 天內對應之繳款日。
- **獨立事件與單筆已繳豁免**：在時間軸保留該週期項目之獨立卡片（標記項目名稱與信用卡繳款日扣款），並支援單筆「✅ 已繳」勾選豁免。

### 5. 動態時間問候語 (Dynamic Time Greeting)
- 根據使用者本地時間區間動態切換問候：
  - 05:00 ~ 11:59：早安
  - 12:00 ~ 17:59：午安
  - 18:00 ~ 04:59：晚安

## Consequences

- 解決手機橫向與直向各處截斷、溢出與擠壓跑版問題，大幅提升行動端體驗。
- 現金流預測精確反映真實資金離帳時間點，避免因刷卡日與繳款日時間差誤導使用者預算規劃。
- 名詞體系更加貼近日常直覺，消除繁中語意認知負擔。
