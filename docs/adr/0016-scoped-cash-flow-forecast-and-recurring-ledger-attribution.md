# 16. 現金流預測與週期收支三態視角分流與權責基準規範 (Scoped Cash Flow Forecast & Recurring Ledger Attribution)

Date: 2026-10-03

## Status

Accepted

## Context

在《My-Money》雙帳本系統中，總覽（Dashboard）、交易明細（Transactions）、帳戶管理（Accounts）與財務分析（Analytics）皆已導入「🌐 全部 (`all`)」、「🏠 公帳 (`household`)」、「🔒 私帳 (`personal`)」三態視角切換器（ADR 0014），且帳戶管理已落實公帳權責淨餘額核算（ADR 0015）。

然而在「現金流預測（`Forecast.tsx`）」與其上游驅動引擎「週期收支（`Recurring.tsx`）」中，仍存在以下斷層：
1. **週期收支缺乏公私帳歸屬**：`recurring_items` 資料表僅綁定建立者 `user_id` 與選填之 `account_id`，未區分該筆固定收支屬於「🏠 公帳」或「🔒 私帳」。當成員使用個人信用卡代為扣繳家庭水電、網路或串流訂閱時，系統無法將其識別為家庭公帳排程，其他家庭成員亦無法在公帳視角看見該固定支出。
2. **現金流預測無法區分視角**：`GET /forecast` 與 `POST /forecast/purchase-check` 僅查詢當前登入者名下之單一帳戶與週期項目，無法切換檢視「家庭公帳未來 30 天是否透支」或「個人私帳未來 30 天是否安全」。
3. **預測起點與帳戶權責脫節**：現金流預測的第 0 天起始餘額未與 ADR 0015 之權責淨可用餘額對齊，且「總覽頁」與「帳戶頁」在計算可支配現金（`disposable`）時，扣除的每月固定支出分攤（`monthlyFixed`）未依視角過濾公私帳，導致私帳視角混入家庭固定開銷。

## Decision

我們決定將三態視角體系（`all` / `household` / `personal`）全面貫穿至「週期收支」與「現金流預測」模組：

### 1. 週期收支公私帳歸屬與共治權限 (`recurring_items.is_shared`)
- **資料結構擴充**：於 `recurring_items` 資料表新增 `is_shared INTEGER NOT NULL DEFAULT 0`（`1` = 🏠 公帳，`0` = 🔒 私帳），並支援自動平滑遷移（Auto-migration）。
- **表單智慧連動與手動覆寫**：
  - 新增／編輯週期收支彈窗增設「🏠 公帳 / 🔒 私帳」二態切換按鈕。
  - 當使用者選擇「扣款／入帳關聯帳戶」時，若該帳戶為共同帳戶（`is_joint = 1`），系統自動預設切換為 `🏠 公帳`；若為個人帳戶（`is_joint = 0`），預設為 `🔒 私帳`，但允許使用者手動切換為 `🏠 公帳`（支援「以個人私卡固定代扣家庭水電／網路費」之代墊場景）。
- **三態檢視與權限邊界（對齊 ADR 0013）**：
  - `Recurring.tsx` 頂部增設「🌐 全部 / 🏠 公帳 / 🔒 私帳」三態切換器，隨視角重算頂部「每月固定支出／收入分攤」與項目列表，並於卡片顯示 `🏠 公帳` / `🔒 私帳` 徽章與建立者名稱。
  - **權限防線**：個人私帳週期項目（`is_shared = 0`）僅建立者本人可見、可改、可刪；家庭公帳週期項目（`is_shared = 1`）對全體家庭成員可見，並由「建立者本人或家庭管理員（`admin`）」共治改刪，後端 API 強制攔截越權操作並回傳 HTTP 403 Forbidden。
- **全站分攤連動**：`GET /accounts/balance?scope=...` 與 `GET /recurring/amortize?scope=...` 嚴格依當前視角過濾 `recurring_items.is_shared`，確保各視角的 `monthlyFixed`（每月固定支出分攤）與 `disposable`（真實可支配現金）精準無誤。

### 2. 現金流預測三態視角與第 0 天權責起點 (`GET /forecast?scope=...`)
- **第 0 天起始基準餘額（Starting Balance）對齊 ADR 0015**：
  1. **🏠 公帳 (`household`)**：`家庭共同現金與存款 (is_joint = 1) - 家庭共同卡總欠款 - 全體成員個人私卡上之家庭公帳代墊額 (shared_debt)`。
  2. **🔒 私帳 (`personal`)**：`本人個人私有現金與存款 (is_joint = 0) - 本人個人信用卡待繳款`。
  3. **🌐 全部 (`all`)**：`本人私有正資產 + 家庭共同正資產 - 本人所有卡債 - 共同卡欠款 - 他人私卡之公帳代墊額`。
- **未來 30 天排程事件過濾與呈現**：
  - 依 `scope` 篩選對應之週期收支（`household` 取全體成員 `is_shared = 1`；`personal` 取本人 `is_shared = 0`；`all` 取兩者聯集）。
  - 排程事件清單（`events`）回傳 `is_shared` 與 `account_name` 資訊，前端於「未來 30 天收支排程」卡片上標示 `🏠 公帳` / `🔒 私帳` 徽章與扣款帳戶名稱。

### 3. 智慧購買力試算三態連動與儲蓄隱私隔離 (`POST /forecast/purchase-check`)
- **視角同步評估**：購買力試算 API 接收當前頁面之 `scope` 參數（`all` | `household` | `personal`），以該視角的第 0 天起始餘額扣除預計消費金額後，模擬未來 30 天對應該視角的週期收支排程，判定是否發生透支（`willOverdraft`）。
- **儲蓄目標隱私隔離**：
  - 在「🔒 私帳 (`personal`)」與「🌐 全部 (`all`)」視角下：同時檢核是否擠壓本人設定之儲蓄目標預留款（`monthly_reserve`）。
  - 在「🏠 公帳 (`household`)」視角下：專注檢核家庭共同基金是否透支，不將成員個人的私密儲蓄目標納入公帳檢核，保護個人儲蓄隱私。

## Consequences

### Positive
- **預測起點與帳戶管理 100% 吻合**：使用者在帳戶頁看到的「💎 淨可用餘額」即為現金流預測折線圖的第 0 天起點，數據邏輯高度一致。
- **支援私卡固定代墊公帳**：家庭水電、瓦斯、串流等綁定個人私卡自動扣繳的公帳開銷，能正確納入家庭公帳現金流預測，消除公帳預警盲區。
- **個人私帳與公帳風險完全解耦**：使用者可獨立檢視「家庭公帳未來 30 天是否需要補錢」以及「個人私帳未來 30 天能否負擔個人消費」。

### Negative / Trade-offs
- 既有已建立之週期收支項目在自動遷移後預設為 `is_shared = 0`（若其綁定之 `account_id` 為 `is_joint = 1` 共同帳戶，遷移邏輯可自動將其升級為 `is_shared = 1`），使用者亦可隨時於介面中調整歸屬。
